클로드 코드와 함께 이 블로그를 처음부터 만들어보면서, HTML/CSS/JavaScript가 각각 어떤 역할을 맡는지 몸으로 느낄 수 있었다. 간단히 정리해본다.

## HTML — 뼈대와 의미

HTML은 페이지에 **어떤 내용이 어떤 역할을 하는지** 알려주는 뼈대 역할을 한다. 제목은 `<h1>`, 글은 `<article>`, 목록은 `<ul>`처럼 태그 자체가 의미를 담고 있어서, 브라우저와 검색엔진이 내용을 제대로 이해할 수 있게 해준다. 이 블로그에서는 마크다운 파일을 빌드 스크립트가 이 HTML 구조로 변환해준다.

## CSS — 보이는 방식

CSS는 그 뼈대에 **디자인**을 입힌다. 이번 프로젝트에서 가장 인상 깊었던 부분은 두 가지였다.

- **CSS 변수(custom property)**로 색상을 한 곳에서 관리하면, 라이트/다크 테마 전환이 값만 바꿔치는 것으로 끝난다는 점
- `@media` 쿼리 하나로 모바일 화면에서도 레이아웃이 깨지지 않게 만들 수 있다는 점

```css
:root {
  --color-bg: #ffffff;
  --color-text: #1a1a1a;
}
```

## JavaScript — 동작과 상호작용

JavaScript는 페이지를 **살아있게** 만든다. 이 블로그에서는 크게 두 가지 일을 한다.

1. 다크 모드 토글 버튼을 누르면 테마를 바꾸고 `localStorage`에 저장해서 다음 방문에도 기억하게 함
2. 검색창에 입력하면 미리 만들어둔 `search-index.json`을 불러와 실시간으로 글 목록을 필터링함

> HTML은 무엇인지, CSS는 어떻게 보일지, JavaScript는 어떻게 움직일지를 담당한다 — 이 역할 구분이 명확해지니 코드를 읽을 때도 훨씬 편해졌다.

셋 중 하나라도 빠지면 지금 같은 블로그는 만들 수 없었을 것 같다. 다음에는 더 다양한 마크다운 문법이나 태그별 글 모아보기 기능도 추가해보고 싶다.
