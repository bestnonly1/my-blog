# 안녕하세요

이 블로그는 **프레임워크 없이** 순수 HTML, CSS, JavaScript만으로 만들어졌습니다. 마크다운 파일을 쓰면 빌드 스크립트가 정적 HTML로 변환해줍니다.

## 지원하는 문법

텍스트를 *기울임*, **굵게**, 또는 ***굵고 기울이게*** 쓸 수 있고, `인라인 코드`도 지원합니다.

링크는 이렇게 씁니다: [Anthropic](https://www.anthropic.com)

이미지도 넣을 수 있어요:

![예시 이미지](https://via.placeholder.com/600x200)

### 코드 블록

```js
function greet(name) {
  console.log(`Hello, ${name}!`);
}
```

HTML 특수문자도 안전하게 이스케이프됩니다: `<div class="test">`
